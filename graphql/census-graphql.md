# Census GraphQL API

Census (now Fivetran Activations) is a reverse ETL and data activation platform that syncs data from cloud data warehouses such as Snowflake, BigQuery, Databricks, and Redshift into operational SaaS applications and destinations. The platform is managed primarily through a REST API, but the domain model maps naturally to a GraphQL schema covering syncs, sources, destinations, segments, mappings, field-level metadata, scheduling, alerting, and organization management.

**Endpoint:** No native endpoint - conceptual schema

**Documentation:** https://fivetran.com/docs/activations/rest-api/api-reference/introduction
